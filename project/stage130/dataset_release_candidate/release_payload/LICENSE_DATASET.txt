WHAT THIS RELEASE CONTAINS
--------------------------

The released company-year panel contains researcher-compiled company
financial-statement fields from publicly accessible CODAL disclosures, together
with author-derived variables and annotations. No TSETMC-derived and no World
Bank-derived field is included in this release; those sources relate only to
the wider study.
